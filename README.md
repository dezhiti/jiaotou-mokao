# 交投模考 · 黑龙江省交通投资集团招聘考试练习网页

一个类「粉笔模考」的**纯静态**答题练习网页，数据来自你提供的 4 套试卷（2024 / 2025 真题回忆版 + 2026 模拟卷一、卷二）。

## 使用方法

直接双击 `index.html` 用浏览器打开即可（无需服务器、无需联网）。推荐用 Chrome / Edge 打开。

## 功能

- **试卷选择**：首页展示 4 套试卷，含题量、建议用时与进度状态（未开始 / 答题中 / 已完成）。
- **限时作答**：按试卷 120 分钟倒计时，时间到自动交卷；答题进度自动保存在浏览器 localStorage，关闭页面后可继续。
- **客观题自动判分**：单选 1 分/题、多选 2 分/题（全对得分）、判断 1 分/题；交卷后即时出分。
- **题型覆盖**：单选题、多选题、判断题、案例分析题、材料写作题。
  - 判断题以「A=正确 / B=错误」作答。
  - 案例分析 / 写作题为**主观题**，支持在线作答，交卷后展示「参考答案」供自评。
- **图片题**：图形推理、立体几何、资料图表等以「原卷页截图」方式展示；图片选项题用字母键（A/B/C/D）作答。
- **答题卡**：右侧答题卡（移动端为底部抽屉）显示作答状态，支持点击跳题、标记题目。
- **成绩报告**：客观题得分、答对 / 答错 / 未答统计、各题型得分条、用时；支持按「全部 / 答对 / 答错 / 未答 / 标记」筛选逐题解析。
- **即时反馈（可开关）**：答一题立刻判对错并显示正确答案与解析，答错自动锁定；关闭后即回到交卷统一判分的模考模式。
- **正确率统计**：答题过程中实时显示本次正确率；首页显示累计已答 / 答对 / 正确率。
- **错题本**：答错的题自动收录，可查看错题（含正确答案与解析）、单题重做 / 全部重做；重做答对后自动移出错题本。
- **重做与重置**：已完成的试卷可「查看报告」或「重新作答」。

## 目录结构

```
刷题网页/
├── index.html          主页（单页应用）
├── css/style.css       样式（粉笔风）
├── js/
│   ├── app.js          应用逻辑
│   └── data.js         题库数据（自动生成，请勿手改）
├── images/             图片题的原卷页截图
├── data/exams.json     结构化题库（JSON）
├── extract/            PDF 提取的纯文本（中间产物）
└── build_data.py       数据构建脚本（PDF 文本 -> exams.json + 图片）
```

## 数据说明

- 题面、选项、答案、解析均来自你上传的 8 份 PDF（4 份题目 + 4 份答案）。
- 因原卷为扫描件，个别图片题 / 图形推理题的文字层缺失，已用「原卷页截图」补全，可能包含相邻题目。
- 判断题答案以答题卡涂卡规则为准（A=正确，B=错误）。
- 仅用于个人学习交流。

## 重新生成数据

如需在其它环境重建题库：

1. 把 8 份 PDF 放到 `N:\BaiduNetdiskDownload\`（或修改 `build_data.py` 中的 `EXAMS` 路径）；
2. 运行 `python build_data.py`，会重新生成 `data/exams.json` 与 `images/`；
3. 运行 `python make_datajs.py`（见下方）生成 `js/data.js`。

> 注：`js/data.js` 由 `data/exams.json` 转出。当前已生成完毕，普通使用无需重跑。
